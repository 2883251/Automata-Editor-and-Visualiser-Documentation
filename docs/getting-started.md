# Getting Started

Welcome! This guide will help you get up and running with the Automata Editor.

## Prerequisites

Before you begin, ensure you have:

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Basic understanding of Turing Machines and formal language concepts
- (Optional) Git installed if you want to contribute to the project

## Installation & Setup

The Automata Editor is a web-based application. Simply navigate to the deployed application URL in your browser. No installation required for users.

## Creating Your First Turing Machine

1. **Sign In** — Log in with your credentials or create a new account
2. **Create New Machine** — Click "New Machine" to start
3. **Configure Alphabet** — Define the input and tape alphabets
4. **Add States** — Use the visual editor to add states (drag on the canvas)
5. **Define Transitions** — Draw arrows between states and specify transition rules
6. **Test Your Machine** — Use the computation visualizer to run your machine on test inputs

## Key Concepts

### Visual Editor vs. Code Editor

The Automata Editor provides two synchronized views:

- **Visual Editor**: Drag-and-drop state diagram editor (left panel)
- **Code Editor**: Text-based machine definition (right panel)

Both views represent the same machine. Changes in one automatically update the other.

### Computation Visualization

After creating a machine, use the **Computation Visualizer** to:

- Step through execution with animated tape movement
- Track the current state and tape position
- Monitor time and space complexity metrics
- Identify acceptance or rejection of input strings
