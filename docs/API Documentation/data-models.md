# Data Models

This page defines the data structures and schemas used throughout the Automata Editor API.

## Topics Covered

### Machine Model
- Machine metadata (name, description, type)
- State definitions
- Transition definitions
- Alphabet configuration
- Execution parameters

### User Model
- User profile information
- Authentication credentials
- Preferences and settings
- Subscription/tier information

### Computation Result
- Execution history
- Tape state snapshots
- Resource metrics (time, space)
- Accept/reject status
- Error information

### Test Case Model
- Test case metadata
- Input specification
- Expected output
- Execution results
- Pass/fail status

### Sharing & Permissions
- Share link structure
- Permission levels
- Expiration settings
- Access logs

### Collaboration Session
- Session metadata
- Active participants
- Synchronization state
- Lock information
