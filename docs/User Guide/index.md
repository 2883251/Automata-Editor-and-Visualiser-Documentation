# User Guide

Welcome to the User Guide for the Automata Editor. This guide covers all features organized by complexity tier.

## Overview

The Automata Editor is organized into three feature tiers:

- **[Basic Features](basic-features.md)** — Core machine creation and visualization
- **[Intermediate Features](intermediate-features.md)** — Testing, debugging, and variants
- **[Advanced Features](advanced-features.md)** — Nondeterminism and collaboration

## Learning Path

**New users** should start with **Basic Features** to understand the dual-editor interface and computation visualization.

Once comfortable, explore **Intermediate Features** including test case management, debugging tools, and support for TM variants.

**Advanced users** can leverage collaborative editing and nondeterministic machine exploration.
